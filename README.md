# LifeStream Blood Bank

A premium React + Tailwind CSS website for a blood bank with a polished healthcare design, modern inventory tools, donor registration, and responsive UX.

## Features

- Premium navigation with mobile hamburger menu
- Hero section with gradient accent, trust badge, and CTA buttons
- Animated quick stats and counters
- Neon-glow blood inventory tracker with urgency filters
- Why donate benefits section with icon cards
- Interactive donor registration form with validation and success states
- Upcoming blood drive listings with location filter
- Testimonials section with smooth card display
- FAQ accordion with accessible expand/collapse
- About and contact sections with premium glassmorphism styling
- Responsive design for mobile, tablet, and desktop

## Available Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Setup

1. Install dependencies:
   `npm install`
2. Start development server:
   `npm run dev`

## Project structure

- `src/App.jsx` — main application layout
- `src/components/` — reusable page sections and UI components
- `src/main.jsx` — app entry point
- `src/index.css` — global Tailwind styling

## Notes

This project uses mock data only and no backend integration, but it is designed to be production-ready and easy to extend.
